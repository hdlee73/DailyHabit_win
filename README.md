# DailyHabit for Windows

안드로이드 앱 [DailyHabit](https://github.com/hdlee73/DAilyhabit)의 윈도우 데스크톱 버전입니다.
기능, 디자인(Claude 앱 스타일: 따뜻한 오프화이트·테라코타·세리프 제목·왼쪽 메뉴), 앱 아이콘(해돋이), 버전 번호를 안드로이드 앱과 맞춥니다.

- **만든이:** 이현덕 (hdlee73@gmail.com)
- **버전:** `VERSION` 파일 (안드로이드 앱과 같은 번호)
- **판본:** 일반용(오늘의 명언) / 천주교인용(오늘의 복음·기도) — 따로 설치되는 두 앱

## 메뉴

오늘의 복음·기도(천주교인용) 또는 오늘의 명언(일반용), 일정, 할 일, 루틴(간단히 보기 기본), 한 줄 일기, 맛집(방문 달력·사진·동네별 지도), 독서(올해 목표), 월간 돌아보기, 설정(백업·엑셀 저장), 앱 정보(업데이트 확인). 장보기는 안드로이드처럼 메뉴에서 숨겨 두었습니다.

## 안드로이드와 다른 점 (윈도우 방식으로 대신한 것)

| 안드로이드 | 윈도우 |
|---|---|
| 휴대폰에 동기화된 구글 캘린더 읽기 | 설정에서 구글 캘린더의 **비공개 주소(iCal 형식)** 를 넣으면 일정 화면·아침 알림에 표시 |
| 알람(AlarmManager)·WorkManager 알림 | 앱이 켜져 있는 동안(창을 닫아도 **트레이**에서) 윈도우 알림으로 아침·루틴·할 일·새 버전 알림 |
| 부팅 후 알림 다시 예약 | 설정의 **Windows 시작할 때 실행** (트레이에서 조용히 시작) |
| 공유 시트 | 내용을 **클립보드에 복사** (메신저·메일에 붙여 넣기) |
| 지도 앱 열기 | 브라우저로 **네이버 지도** 검색 |
| 알림의 ‘완료’ 버튼 | 알림을 누르면 해당 화면이 열림 |
| APK 업데이트 설치 | 앱 정보에서 **.msi를 내려받아 바로 설치** (앱이 잠시 닫혔다가 다시 열림) |

## 업데이트 (덮어 설치)

설치 파일의 업그레이드 코드를 판본마다 고정해 두어(`build.gradle.kts`의 `upgradeUuid`), 새 버전 .msi가 기존 설치본 위에 덮어 설치되고 기록(`%APPDATA%\DailyHabit…`)은 그대로 남습니다. 천주교인용은 v1.0.0이 쓰던 업그레이드 코드와 데이터 폴더를 이어받습니다.

## 릴리스

`VERSION`을 올려 `main`에 올리면 GitHub Actions(windows-latest)가 테스트 후 두 설치 파일을 만들어 릴리스합니다.
태그: `v<버전>` (일반용), `v<버전>-catholic` (천주교인용). 앱의 업데이트 확인도 이 태그 규칙으로 내 판본을 찾습니다.

## 개발

```bash
./gradlew run                          # 일반용 실행
./gradlew run -Pedition=catholic       # 천주교인용 실행
./gradlew test                         # 테스트 (기록은 build/test-data에만 씀)
./gradlew packageMsi -Pedition=catholic
```

기술: Compose Multiplatform Desktop (Kotlin 2.1, Compose 1.7.3, Material 3), SQLite JDBC, Jsoup, org.json.
